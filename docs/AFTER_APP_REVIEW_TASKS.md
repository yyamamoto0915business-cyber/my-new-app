## 全体の方針：すべての画面を PC・タブレット・スマホの3つで使いやすくする

ここにあるタスクも、それ以外の画面も、**PC・タブレット・スマホの3つの画面幅で使いやすい**ことを基本にする。
直すときは、3つすべての幅で見た目と操作を確かめる。

**今の作りの問題**
- 画面の切り替えは、ほとんど `min-[900px]`（900px 以上を PC、未満をスマホ）の2段階だけ（約1,000か所）
- **タブレット向けの形がない。** iPad の縦向き（768〜899px くらい）はスマホの形が横に引き伸ばされ、横向き（1024px くらい）はPCの形が窮屈に入っている

**目安にする画面幅**

| 種類 | 幅 | 例 |
|---|---|---|
| スマホ | 〜767px | iPhone |
| タブレット | 768〜1099px | iPad の縦・横 |
| PC | 1100px〜 | ノートPC・デスクトップ |

**進め方**
- [x] 画面幅の区切りを共通の決まりにする（2026-11-06：tablet 600px / pc 900px を globals.css に。新しいところは tablet: / pc: を使う）
- [x] よく使う画面から順に、タブレットの形を足す（ホーム・イベント詳細・投稿は 2026-11-06。マイページ・主催者の画面は 2026-11-09 に確認：もともと崩れはなく、上のタブを同じ幅に・集計のカードを4つ並びにした）
- [ ] 新しく作る画面・直す画面は、最初から3つの幅で作る

## 2-2. ゲームを自由に組み立てられるようにする

**なぜ：** 今のゲームは決まった7種類（スタンプラリー・クイズラリー・謎解き街歩き・ミッション・フォトラリー・クーポンラリー・チェックイン）から選ぶだけ。投票やトーナメント表など、主催者がやりたい企画に合わせて自由に作れるようにしたい。

**考え方：** 種類を1つずつ増やし続けるのではなく、**部品（ブロック）を組み合わせて作れる**ようにする。
今の「ミッション」は、すでに部品を組み合わせる作りになっている（スポットに行く・写真を投稿・キーワード入力・チェックイン・クイズ・友だちと参加）。これを広げるのが近道。

**足したい部品**
- [ ] 自由に書いて送る（アイデア・名前・感想などを集める）
- [ ] 投票する（候補から選ぶ。1人1票 / 複数票）
- [x] アンケート（選択肢・段階評価）（2026-11-07：1つ選ぶ・いくつでも・5段階・自由記述、集計とCSV。migration 00125）
- [x] 抽選（参加者からランダムに選ぶ）（2026-11-07：賞ごとに抽選・取り消して引き直し・結果発表。migration 00124）

**部品とは別に作るもの**
- [x] **トーナメント表**（2026-11-09：勝ち抜き・リーグ戦、結果を入れると勝ち上がる、参加者はログインなしで見られる。migration 00126）：参加者やチームを登録 → 組み合わせを作る → 勝ち上がりを主催者が入力 → 参加者は今の対戦表をスマホで見られる。リーグ戦（総当たり）もあるとよい
- [ ] 投票の結果発表・ランキングの画面

**作成画面**
- [ ] 最初に「テンプレートから作る（今の7種類＋投票・トーナメントなど）」か「自由に組み立てる」かを選ぶ
- [ ] 部品を並べ替え・追加・削除でき、横のスマホのプレビューですぐ確かめられる
- [ ] PC・タブレット・スマホの3つの幅で作れる

**部品が増えても迷わないように**
- [ ] 部品を「集める（写真・文字）」「答える（クイズ・投票・アンケート）」「行く（スポット・チェックイン）」「もらう（クーポン・抽選）」のように分けて見せる
- [ ] よく使う組み合わせはテンプレートにして、そこから少し変えるだけで作れるようにする
- [ ] 新しい部品は、どれも同じ作り（設定項目・プレビュー・集計）で足せるようにしておく

**順番の案：** 2 の投票ゲームを、まず「自由に書いて送る」「投票する」の部品として作る → それを使ってテンプレートの仕組みを作る → トーナメント表
